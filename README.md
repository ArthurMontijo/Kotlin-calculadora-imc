# Kotlin-calculadora-imc

## Descrição
Aplicativo Android que calcula o Índice de Massa Corporal (IMC) com base no peso e na altura informados pelo usuário.

## Tecnologias utilizadas
- Kotlin
- Android Studio  25.0.3
- Jetpack Compose

## Funcionalidades
- Informar o peso em quilogramas.
- Informar a altura em metros.
- Calcular o IMC.
- Arredondar o resultado do IMC.
- Exibir o resultado na tela com duas casas decimais.

## Como executar
1. Abra o projeto no Android Studio.
2. Aguarde a sincronização do Gradle.
3. Execute o aplicativo em um emulador ou dispositivo Android.
4. Informe o peso e a altura.
5. Clique em **Calcular** para visualizar o IMC ou em **Arredondar** para arredondar o resultado para cima.
